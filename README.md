AI systems rarely fail alone. They fail where prompts cross privilege boundaries, artifacts enter runtimes, tools convert text into action, and claims detach from evidence.

Always the Vectors hunts those transitions:

* **Dangerous pickles** · unsafe serialization and hostile model artifacts
* **Loop-hijacking prompts** · prompt injection and agent control-flow failures
* **Hallucinated crimes** · fabricated claims, contaminated evidence, and broken provenance
* **Hidden vectors** · authorization, tool-use, and execution boundaries

## KRUC

**Kill Rate Under Conditions.**

A system is not secure because it survived one demonstration. Find the condition that kills it, preserve the evidence, fix the boundary, and run it again.

**KB, the KRUC Bandit, hunts those conditions.**

## Current build

**KRUC Edge-Case Lab** · converting real failure modes into reproducible cases, explicit expectations, and machine-readable evaluation results.

`Status: building in public`

## Operating standard

> Reproduce the failure. Preserve the evidence. Name the boundary. Ship the fix.
